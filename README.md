# crossword-lite —— 迷你英文填字游戏

纯 Python 标准库实现的迷你填字游戏：**内置词库 → 自动生成交叉布局 → 回溯求解器演示 → 交互填词**，无第三方依赖。

## 玩法

- 程序用内置英文词库自动生成一张 15×15 填字棋盘（默认 12 个单词，互相交叉）。
- 每个单词按标准填字规则编号，题面给出中文释义或字母数提示。
- 在终端里按 `题号+A(横向)/D(纵向)+单词` 的格式填词（例：`3A APPLE`），填满即通关。

## 用法

```bash
python -m crossword_lite                  # 交互填词（中文提示）
python -m crossword_lite --auto --games 3 --seed 42   # 自动演示：生成 3 局并求解
python -m crossword_lite --solve --seed 7  # 展示一次"生成→求解"全过程
python -m crossword_lite --seed 7 --size 13 --max-words 10  # 自定义棋盘/词数
```

交互命令：`3A APPLE` 填词 · `show` 看答案 · `q` 退出。

## 实现说明

- **生成器**：首词取词库中最长的词居中横放，其余词随机枚举与已放单词的交叉点（字母相同、垂直邻格为空、两端留白），用 `random.Random(seed)` 保证同种子可复现。
- **求解器**：回溯 + MRV（最少候选优先）启发式，**只用题槽和词库搜索，不偷看生成时的答案**——因此它有时会给出与生成时不同、但同样合法的填充方案，这是真正的搜索行为。
- **编号**：标准填字编号规则（单词起点从左上到右下编号）。

## 诚实局限

- 词库只有 **104 个**常见英文单词，题面释义覆盖约 60 个，其余只提示字母数——玩几局就会眼熟。
- 求解器允许不同题槽复用同一个词（生成器不会），与正式填字规范略有出入。
- 没有黑色分隔格：棋盘空白处即分隔，布局不如报纸填字紧凑。
- 纯文本界面，无图形/存档/悔棋/网络对战；Python 3.10+，纯标准库。
